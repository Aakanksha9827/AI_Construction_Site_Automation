
AI-Powered Construction Site Automation and Intelligence Platform

Project Overview
This project is a Construction Management System developed to simplify and manage construction site activities through a web-based platform.

Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Maven
- MySQL
- HTML
- CSS
- Thymeleaf
- Apache Tomcat

Key Features
- User and Role Management
- Construction Project Management
- Labor Management
- Inventory Management
- Cost Estimation
- Finance Management
- Construction Duration Prediction
- AI-Based Interior Design Assistance

Project Objective
To improve the efficiency of construction management by organizing project information and supporting construction planning.
